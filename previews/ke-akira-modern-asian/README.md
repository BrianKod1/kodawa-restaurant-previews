# Akira Modern Asian — Concept Website

A polished, responsive restaurant concept website built for the Kodawa Labs Kenya Restaurant Collection.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/` containing the supplied Akira photography

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy
Upload the folder to your existing showcase repository and link it from the collection homepage. It can also be deployed directly to Cloudflare Pages, Netlify, Vercel or GitHub Pages.

## Notes
The reservation form is a front-end demonstration. Connect it to Formspree, a CRM, WhatsApp, ReserveAI or a custom backend before production use.
