# HERO Restaurant — Immersive Concept

A Kodawa Labs restaurant website concept built around Japanese precision, cinematic craving and immersive sound.

## Features

- Editorial white, black and red art direction
- Optional browser-generated ambient soundtrack
- Loading sequence
- Scroll-led light-to-dark progression
- Plate lift, chopstick, sauce ripple and dessert sparkle micro-interactions
- Appetite-first signature dish storytelling
- Reservation CTAs
- Mobile responsive
