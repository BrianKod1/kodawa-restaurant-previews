# Top Rise Restaurant — Website Concept

Static restaurant website concept created for the Kodawa Labs Kenya Restaurant Collection.

## Deployment path

Place this folder in the repository as:

`previews/ke-top-rise-restaurant/`

Expected URL:

`https://showcase.ouniverse.space/previews/ke-top-rise-restaurant/`

All CSS, JavaScript and image paths are relative for Cloudflare Pages compatibility.
