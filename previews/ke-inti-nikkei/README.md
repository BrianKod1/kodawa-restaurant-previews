# INTI — A Nikkei Experience

A cinematic, responsive restaurant concept built for the Kodawa Labs Kenya Restaurant Collection.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `assets/`
- `menus/`

## Highlights
- Scroll-driven light transitions
- Editorial sections designed to work as standalone social posts
- Procedural ambient sound generated in-browser
- Direct reservation link
- Downloadable food, drinks, dessert and bento menus
- Responsive mobile layout

## Deploy
Place the `ke-inti-nikkei` folder inside the repository's `previews` directory.

Live path:
`https://showcase.ouniverse.space/previews/ke-inti-nikkei/`

## Note
This is an independent Kodawa Labs concept and not the official INTI website.
