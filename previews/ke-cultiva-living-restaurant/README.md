# Cultiva — Living Restaurant Experience

A responsive Kodawa Labs concept built around sustainability, community and the journey from soil to plate.

## Included
- Scroll-driven day-to-night lighting
- Optional in-browser farm ambience
- Farm, people, menu, fermentation and recognition storytelling
- Food, drinks and brunch menu PDFs
- Mobile responsive design

## Deployment
Place the folder inside:

`kodawa-restaurant-previews/previews/ke-cultiva-living-restaurant/`

Expected URL:

`https://showcase.ouniverse.space/previews/ke-cultiva-living-restaurant/`

This is an independent Kodawa Labs concept and not the official Cultiva website.
