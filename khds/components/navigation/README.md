# KHDS Navigation

## Mission

Guide the guest through the restaurant experience without interrupting immersion.

Navigation should make exploration effortless while keeping the restaurant’s identity and primary reservation action clear.

---

## Purpose

The Navigation provides access to the restaurant’s main information and actions.

It should support the guest journey without becoming the dominant visual element.

---

## Primary Goal

Create clarity without breaking atmosphere.

---

## Required Characteristics

A KHDS Navigation should:

- make primary destinations easy to understand
- keep reservation accessible
- remain visually restrained
- preserve the emotional tone of the experience
- adapt clearly between desktop and mobile
- support keyboard and assistive-technology use
- avoid overwhelming the guest with choices

---

## Information Priorities

Navigation should prioritize:

1. Restaurant identity
2. Reservation
3. Menu
4. Story or About
5. Location and Contact

Secondary information should not compete with these primary actions.

---

## Anti-patterns

Avoid:

- excessive navigation links
- multiple competing booking actions
- unclear labels
- oversized navigation that dominates the Hero
- decorative motion without purpose
- hidden reservation access
- inconsistent desktop and mobile destinations
- menus that are difficult to close or escape

---

## Success Criteria

The guest should be able to answer:

“Where can I go next?”

and

“How can I reserve?”

without losing the feeling created by the page.
