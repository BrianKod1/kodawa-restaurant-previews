# Reservation

## Observation

Mawimbi treats reservation as an important but non-exclusive path into the restaurant.

The website makes booking highly visible while still stating that reservations are not essential.

Guests are repeatedly encouraged to reserve if they want certainty, but the restaurant also preserves flexibility for walk-ins and other booking methods.

The reservation experience therefore combines:

- persistent booking access
- multiple booking channels
- direct restaurant communication
- group-booking escalation
- deposits for larger bookings
- human confirmation

This creates a hybrid reservation model rather than a purely automated one.

Mawimbi places a “Book A Table” action prominently in the website navigation and repeats reservation calls-to-action throughout the site.

## Possible Limitation

The reservation ecosystem provides flexibility, but the guest encounters several possible pathways:

- booking widget
- WhatsApp
- email
- group booking
- event booking
- in-person booking

This is valuable when needs differ.

It can become confusing if the guest does not know which path applies to them.

The strongest future system may preserve multiple channels while presenting one clear decision structure:

Standard Table

↓

Book Now

Group

↓

Group Booking

Event

↓

Plan an Event

Special Request

↓

Talk to the Team

This is a design interpretation rather than evidence of actual booking failure.

## Current Reservation Insight

Mawimbi suggests that the strongest hospitality reservation system may not be fully automated or fully manual.

Instead, automation can follow complexity.

Simple reservations can move quickly.

Complex hospitality can become more human.

The emerging model is:

Self-Service Where Possible

↓

Human Hospitality Where Valuable

That distinction may become important for KHDS because restaurants do not merely process table inventory.

They also manage:

- celebrations
- groups
- deposits
- special requests
- events
- high-value guest relationships

The next question is whether Mawimbi's current multi-channel model creates seamless flexibility or unnecessary fragmentation.

That cannot be determined from the website alone.
