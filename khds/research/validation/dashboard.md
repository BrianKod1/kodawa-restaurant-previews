# Purpose

The KHDS Validation Dashboard provides:

an operational view

of:

the current research system.

It tracks:

- research volume
- pattern maturity
- Candidate confidence
- promotion watches
- contradiction pressure
- unresolved tensions
- below-Candidate directions
- business opportunities
- evidence limitations
- Track A research status
- Track B production status
- next validation priorities

This dashboard does not:

create:

new governance decisions.

Canonical pattern governance lives in:

`candidate-patterns.md`

The official pattern index lives in:

`../../patterns/registry.md`

The dashboard must:

mirror:

those records.
