# KHDS Validation

## Purpose

This directory contains the governance layer for KHDS research.

Its purpose is to determine:

- which findings are still observations
- which findings qualify as Candidate patterns
- which Candidates have enough repeated support to become Emerging
- which patterns survive contradiction
- which patterns need narrowing
- which patterns need renaming
- which patterns should be demoted
- which patterns eventually qualify as Validated
- which research-derived patterns may later become KHDS Principles

The validation layer exists to prevent:

interesting observations

from becoming:

design doctrine

too early.

---

# Governance Principle

KHDS does not reward:

confirmation.

It rewards:

survival under pressure.

For every pattern ask:

> **What restaurant would make this fail?**

A useful contradiction may improve KHDS more than:

another supporting case.

---

# Research Maturity Model

KHDS follows:

Observed

↓

Candidate

↓

Emerging

↓

Validated

↓

KHDS Principle

Each stage represents:

increasing evidentiary confidence.

---

# Observed

An interesting behaviour has been identified.

It may come from:

one restaurant

or

one dimension of research.

Observed does not mean:

transferable.

---

# Candidate

The behaviour appears meaningful enough to:

track formally.

Candidate status requires:

- clear abstraction
- meaningful evidence
- a distinct question
- enough potential transferability to justify further testing

Candidate does not mean:

correct.

Candidates should be:

actively attacked.

---

# Emerging

The pattern has survived:

repetition

and

materially different independent cases.

Emerging patterns have stronger transferability.

But they are still:

research-derived hypotheses.

They have not yet reached:

Validated.

---

# Validated

A future Validated pattern should require:

- repeated support across broad independent contexts
- meaningful geographic diversity
- meaningful operating-model diversity
- deliberate contradiction testing
- clear boundaries
- survival after definition pressure
- implementation evidence where relevant
- operational or behavioural evidence where the claim requires it

Current Validated count:

0

---

# KHDS Principle

A KHDS Principle should represent:

a high-confidence research-derived rule

that has survived:

broad testing

and

practical translation.

No research-derived pattern has yet reached:

KHDS Principle.

Current count:

0
