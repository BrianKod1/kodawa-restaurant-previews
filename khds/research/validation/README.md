# KHDS Validation

## Purpose

The KHDS Validation layer determines what the current research evidence actually justifies.

It separates:

- independent hospitality evidence
- Kodawa Labs implementation validation
- candidate patterns 
- emerging patterns
- partially supported findings
- research tensions
- business opportunities and gaps

Validation exists to prevent assumptions from becoming KHDS knowledge too early.

---

# Core Principle

Evidence before promotion.

A pattern should advance only when the evidence supports greater confidence.

---

# Validation Responsibilities

The validation layer answers:

- What patterns are currently being tested?
- Which patterns are becoming stronger?
- Which findings remain uncertain?
- Which findings require technical or operational evidence?
- What contradictions exist?
- Which business gaps are appearing repeatedly?
- What should be researched next?

# Validation Rule

The current three-restaurant research set is not sufficient for automatic promotion to Validated.

Broader validation should consider:

- approximately 5–10 or more independent restaurant studies
- restaurant-category diversity
- geographic diversity
- brand diversity
- different reservation models
- contradictory evidence
- implementation viability
- guest behaviour evidence where available

Count alone is not enough.
