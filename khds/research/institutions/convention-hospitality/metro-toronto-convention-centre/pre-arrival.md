# Pre-arrival / Event Preparation

Public-evidence coverage: partial

## Research question

How does a contracted event become operationally ready when floor plans, move-in schedules, security, supplier services, catering, exhibitor orders and accessibility requirements have separate deadlines or approval paths?

## Contracted event does not equal approved configuration

Detailed floor plans are required for exhibit halls, registration areas and public-area activities. Preliminary plans should be approved before exhibit-space sales are confirmed; final plans require approval by MTCC's Safety Compliance Manager and are due sixty days before move-in. [S4]

Therefore:

Event Contracted != Event Layout Approved.

Booth Space Sold != Final Floor Plan Approved.

Commercial Exhibit Plan != Operationally Approved Exhibit Plan.

## Move-in has its own approval state

The Licensee must submit a detailed move-in/out schedule at least three weeks before first move-in, covering contractors, exhibitors, show-management deliveries and freight. [S4]

Therefore:

Event Layout Approved != Move-In Schedule Approved.

MTCC retains final approval and may limit dock space or times based on operational needs. [S4]

Therefore:

Requested Move-In Time != Approved Dock Capacity.

## Exhibitor readiness depends on Show Management

MTCC directs exhibitors to the Show Management-provided Exhibitor Kit or Show Manager for move-in/out details. [S6]

Therefore:

Venue Contracted != Exhibitor Move-In Instructions Complete.

## Voyage Control creates a separate logistics state

Exhibitors may need a Show Manager-provided code and a reserved unloading time. [S4][S6]

Therefore:

Exhibitor Registered != Loading Slot Reserved.

## Security is split between venue and organizer

MTCC maintains perimeter/internal patrols, while the Licensee is responsible for complete security within licensed event areas from move-in through move-out. MTCC retains final approval of event security requirements. [S4]

Therefore:

Venue Security Present != Event Security Fully Provisioned.

Organizer Security Plan != Security Requirement Finalized.

## Catering readiness is separate

The Operating Guidelines require menu selections and event details in advance and later attendance/dietary guarantees. [S4]

Therefore:

Event Contracted != Catering Ready.

## Exhibitor services have their own ordering state

Exhibitor Services supports advance ordering for venue services. [S4][S5]

Therefore:

Exhibitor Confirmed != Exhibitor Services Provisioned.

## Accessibility can require individual action

Accessible formats and communication supports are available on request, while emergency-evacuation accommodation should be communicated to Security. [S10]

Therefore:

Accessible Facility != Every Individual Accommodation Pre-Provisioned Automatically.

## Strongest pre-arrival boundaries

1. event contract versus layout approval;
2. booth sale versus final floor-plan approval;
3. commercial plan versus operational approval;
4. layout approval versus move-in approval;
5. requested move-in versus approved dock capacity;
6. venue contract versus exhibitor instructions complete;
7. exhibitor registration versus loading-slot reservation;
8. venue security versus event security provisioned;
9. organizer security plan versus final venue requirement;
10. event contract versus catering readiness;
11. exhibitor confirmation versus service provisioning;
12. accessible facility versus individualized accommodation automatically provisioned.

## Evidence limitations

The public record does not establish plan-approval turnaround, rejection rates, dock conflict frequency, late-order rates, security-plan rework, or a shared event-readiness dashboard.
