## Case purpose

Case #39 tests whether a multi-event stadium creates meaningful architecture pressure because a guest's ticket, admission, seat, hospitality space, dining, membership, accessibility and time entitlements can differ while the guest still experiences one venue and one event relationship.

Primary falsification question:

Does stadium hospitality require a distinct responsibility architecture because ticketing, security, seat entitlement, Premium-space access, membership, dining and event-specific rules operate as separate but interdependent states, or can the observed structure be sufficiently explained as ordinary event ticketing with premium hospitality added on top?

## Core institutional mechanism

The strongest Case #39 mechanism is:

**Layered Entitlement Across Event States**

A guest can experience one event while holding several distinct states:

- purchaser;
- ticket holder;
- admitted attendee;
- seat holder;
- Premium guest;
- lounge or suite user;
- dining guest;
- member;
- transferred-ticket user;
- accessibility-supported participant. [S3][S4][S5][S6][S13][S16][S17]

## Falsification requirements

### Layered Entitlement Across Event States

Would weaken if ticket, admission, seat, Premium-space, dining and timing states are operationally collapsed into one simple entitlement with no meaningful effect on responsibility or recovery.

### Ticket / Admission Separation

Would weaken if successful ticket purchase reliably completes admission without materially separate security, entrance or credential states.

### Role-Aware Guest State

Would weaken if purchaser, member, attendee, Premium guest and transferred-ticket user distinctions have no meaningful operational consequence.

### Event-Specific Policy Partitioning

Would weaken if non-football and football rule differences are trivial and do not materially change guest preparation, access or recovery.

### Event Clock / Hospitality Clock Separation

Would weaken if pre/post-event hospitality timing has no material effect on guest entitlement or service ownership.

### Recurring Event Entitlement

Would weaken if seasonal Premium membership functions only as a bundle of unrelated tickets without persistent relationship rights.

### Commercial Journey Economics

Would weaken as an architecture concern if acquisition path has no meaningful connection to cost, service burden, ancillary spend, retention or contribution.

No such financial test has yet been performed.

## Contradiction record

### One event without one entitlement state

The guest-facing event is singular while permissions and service rights can be layered.

### Valid ticket without guaranteed completed entry

Security, assigned entrance and credential use remain distinct states.

### Stadium admission without universal hospitality access

Premium spaces require product-specific entitlement.

### Premium seat without seat-only value

Some Premium products add dining, space, timing and persistent service rights.

### One building without one rule system

Football and non-football operating rules can differ.

### Event end without immediate relationship closure

Premium access, transport, billing and membership can persist.

### One purchaser without necessarily one final attendee

Transfer and Ticket Exchange create role separation.

### Higher price without proven higher contribution

Commercial value cannot be inferred from package price alone.

### One guest journey without one proven data system

Relevant identity and entitlement may need to cross teams, but no synchronized internal architecture is established.
