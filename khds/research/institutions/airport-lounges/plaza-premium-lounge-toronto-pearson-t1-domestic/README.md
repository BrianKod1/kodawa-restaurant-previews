# Case #32 - Plaza Premium Lounge Toronto Pearson Terminal 1 Domestic

Public-evidence coverage: partial

## Institution

Plaza Premium Lounge Toronto Pearson Terminal 1 Domestic is being studied as an airport lounge with direct-pay, walk-in, pass-based, partner-credential, group and optional-service access pathways.

Sector: airport-lounges

Research access date: 2026-10-02.

This dossier is based on inspected public sources. It is not an on-site audit, transaction test, capacity test, accessibility assessment, service-recovery test or proof of representative passenger outcomes.

## Research role

Case #32 tests whether the provisional Role-Partitioned / Multi-Relationship Hospitality Architecture observed in earlier KHDS cases recurs in a compact, non-lodging transit environment.

The primary falsification question is:

Does Role-Partitioned / Multi-Relationship Hospitality Architecture recur in a non-lodging airport lounge where pre-booked guests, walk-ins, passholders, partner-credential users, groups and optional-service users overlap, or do the differences reduce to one simple paid-access lounge product?

The case deliberately removes several features present in earlier research:

- no hotel room relationship;
- no residential stay;
- no private-club membership requirement;
- no destination-scale mixed-use complex;
- no assumption that passenger status itself creates lounge entitlement.

## Initial boundaries under test

The evidence creates several distinctions worth testing without treating them as validated patterns:

Passenger eligibility != lounge entitlement.

Lounge admission != entitlement to every service.

Advance booking != walk-in relationship.

Pass entitlement != direct-purchase relationship.

Shared operator identity != identical product entitlement.

Service availability != admission availability.

Physical co-location != uniform service access.
