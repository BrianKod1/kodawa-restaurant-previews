## Case purpose

Case #40 tests whether a major international airport creates meaningful hospitality architecture pressure because one traveller's passenger role, terminal, controlled zone, immigration state, baggage state, hospitality eligibility and responsibility owner can change while the traveller still experiences one airport journey.

Primary falsification question:

Does Singapore Changi Airport require a distinct hospitality responsibility architecture because passenger identity, flight status, terminal, airside/landside access, immigration, security, baggage and hospitality services cross multiple control boundaries, or can the observed structure be sufficiently explained as ordinary airport operations with passenger amenities layered on top?

## Falsification requirements

### Hospitality Continuity Across Controlled Passenger States

Would weaken if changes in passenger role, controlled zone, immigration, baggage or terminal have no meaningful effect on hospitality eligibility, responsibility or recovery.

### Controlled-State Hospitality

Would weaken if hospitality services can be understood adequately without considering controlled passenger state.

### Nested Hospitality Dependency

Would weaken if lounges, hotels and other embedded services operate independently of wider airport access, terminal, baggage or journey conditions.

### Local Entitlement / Global Journey Eligibility

Would weaken if a valid local booking or entitlement is always sufficient for service use regardless of wider journey state.

### Multi-Owner Recovery

Would weaken if failures consistently resolve through one clear responsible organization without meaningful cross-party handoff.

### Commercial Journey Economics

Would weaken as an architecture concern if hospitality path has no meaningful relationship to acquisition cost, service burden, ancillary spend, repeat value or contribution.

No such financial test has been performed.
