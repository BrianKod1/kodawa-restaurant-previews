# Case #35 - Great Wolf Lodge Niagara Falls

Public-evidence coverage: partial

## Institution

Great Wolf Lodge Niagara Falls is being studied as a family waterpark resort combining overnight accommodation, registered-guest-only waterpark access, complimentary family activities and separately purchasable attraction, dining and cabana products.

Sector: waterpark-resorts

Research access date: 2026-10-08.

This dossier is based on inspected public sources. It is not an on-site audit, transaction test, wristband-system audit, accessibility assessment, service-recovery test or proof of representative guest outcomes.

## Research role

Case #35 tests whether the provisional Role-Partitioned / Multi-Relationship Hospitality Architecture recurs in a resort where the lodging relationship itself creates a base entitlement and narrower optional products are layered onto that stay.

The primary falsification question is:

Does Role-Partitioned / Multi-Relationship Hospitality Architecture recur in a family waterpark resort where the lodging relationship creates base waterpark entitlement while cabanas, attraction passes, dining packages and other add-ons create narrower entitlements, or are those differences fully explained by conventional resort bundling and ancillary sales?

Case #35 deliberately tests a cleaner entitlement structure than Case #34:

- overnight lodging;
- registered-guest-only waterpark access;
- waterpark passes included with the stay;
- optional attraction passes;
- optional dining packages;
- reservable cabanas;
- an RFID wristband that can combine waterpark ticket, room key and optional purchasing functions.

## Initial boundaries under test

Registered guest != general resort visitor.

Lodging reservation != every optional resort entitlement.

Waterpark eligibility != attraction-pass entitlement.

Waterpark eligibility != cabana entitlement.

Waterpark access != room-possession duration.

Registered occupancy != unlimited additional guests.

Meal-package entitlement != ordinary dining purchase.

Shared wristband credential != proof of unified operational responsibility.

Included experience != separately purchased experience.

Physical presence in the waterpark != entitlement to every premium product inside it.
