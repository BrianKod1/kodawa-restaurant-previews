# KHDS Pattern Registry

## Purpose

The KHDS Pattern Registry is the official index of hospitality patterns tracked by KHDS.

It records:

- research-derived patterns
- their current maturity
- their independent evidence
- existing implementation patterns
- partially supported patterns

Detailed research reasoning lives in:

`khds/research/validation/candidate-patterns.md`

This registry should remain concise and authoritative.

# Promotion Rule

A pattern should not become Validated solely because it appears across the current three-restaurant research set.

Promotion should consider:

- broader independent evidence
- restaurant-category diversity
- geographic diversity
- contradictory evidence
- repeatability
- implementation viability
- guest behaviour data where available

---

# Registry Rules

1. This registry is the official KHDS pattern index.

2. Detailed research reasoning belongs in `research/validation/candidate-patterns.md`.

3. Independent restaurant evidence determines research maturity.

4. Kodawa Labs concepts do not count as independent evidence.

5. Existing implementation patterns must remain separately classified until formally validated.

6. Supporting behaviours are not automatically Candidate Patterns.

7. Research tensions are not patterns.

8. Website observation must not be used to claim technical or operational facts that cannot be verified.

9. If a formal KHDS pattern exists but is not represented here, the registry is incomplete.
