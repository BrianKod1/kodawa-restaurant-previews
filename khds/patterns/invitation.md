# Invitation Pattern

## Purpose

Transition the guest from initial visual impact into the restaurant’s emotional promise.

The Invitation should answer:

- Why should this place matter to me?
- What kind of experience is being offered?
- What should I feel before I continue?

## Typical Structure

1. Sequence label or eyebrow
2. Short emotional statement
3. Supporting line
4. Generous visual pause

## KHDS Responsibilities

- Reading width
- Vertical rhythm
- Responsive spacing
- Typographic hierarchy
- Accessible document structure

## Restaurant Responsibilities

- Copy
- Tone
- Brand language
- Theme values
- Any restaurant-specific imagery

## Foundation Alignment

- Emotion before Interface
- Story before Features
- Restraint before Complexity
- Pacing is our Signature
- Respect the Brand

## Validation Questions

- Does this deepen the guest’s interest?
- Is the message memorable?
- Is the section calm enough to function as a pause?
- Could anything be removed?
- Does the language belong unmistakably to this restaurant?
